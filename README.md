# Student Registration System

A desktop student management application built with Java Swing. No MySQL or Tomcat required.

## Features
- Dashboard with total student and course counts
- Register, search, update, and delete student records
- Email and student ID validation
- Persistent local TSV storage

## Requirements
Java JDK 11 or later.

## Run
```bash
javac Main.java
java Main
```

Records are stored in `students.tsv` in the working directory. This file is ignored by Git. Do not commit real student personal data.
